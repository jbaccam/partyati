# Host a Party!

A Roblox tycoon about throwing parties. Build up your house, invite guests and keep them happy:
NPC guests arrive, their satisfaction rises and falls with how the party is going, and chores
(cleaning up, restocking, fixing things) have to be kept up with. Running a good party earns money,
and money unlocks bigger and better parties.

- `house-optimization/`: the optimized neighborhood house models, door runtime and repair notes
  that the game is built on (see its README).
