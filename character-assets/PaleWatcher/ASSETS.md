# Pale Watcher asset provenance

- Visual design reference: six character images supplied by the user in this task (eyeless pale humanoid with palm eyes, black claws, and draped skin).
- Geometry, UVs, deformation skeleton, sample idle, and procedural texture materials: newly authored in Blender by `build_character.py`. No downloaded meshes or Creator Store assets used.
- The reference character design is not claimed as original. This is a modeled interpretation of the supplied references, not the original film/sculpture mesh.
- Color and normal PNGs are baked from the authored Blender shaders. Reference photographs are not projected onto the mesh or included in the export.
- This standalone asset is not placed into Copy The Scene or any existing Studio place.
- Revision 2: anatomy and skin revised after direct visual analysis of the same user references; see `SKIN_ANALYSIS.md`. Three 4096-pixel PBR maps are baked from authored spatial pigmentation, pore/wrinkle shaders, and varying roughness. A hidden higher-resolution sculpt source is retained for editing.
